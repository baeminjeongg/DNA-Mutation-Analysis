1. 프로젝트 소개: 이 프로젝트는 DNA 염기 하나의 치환이 아미노산 서열에 어떤 영향을 미치는지 분석하는 것을 목적으로 한다. 처음에는 교육용 DNA 서열을 활용하여 염기 치환에 따른 아미노산 변화를 비교하려고 했다. 하지만 실제 생물학적 사례를 적용하면 분석의 의미를 더 구체적으로 이해할 수 있다고 생각하여 겸상적혈구빈혈(Sickle Cell Disease)과 관련된 HBB 유전자 변이를 분석 대상으로 선정하였다. 공개된 HBB 기준 서열과 실제 임상 변이 정보를 활용하여 정상 서열과 변이 서열을 비교하고, DNA 염기 치환에 따른 코돈과 아미노산의 변화를 확인하였다.

2. 분석 대상 및 배경: 이번 분석의 대상은 겸상적혈구빈혈과 관련된 HBB 유전자이다. HBB 유전자는 헤모글로빈의 베타 글로빈 사슬을 만드는 데 관여한다. ClinVar에서 확인한 변이는 c.20A>T이며, rs334로도 알려져 있다. 이 변이는 DNA의 20번째 염기 A가 T로 치환되는 변화로, 단백질 수준에서는 글루탐산(Glutamic acid)이 발린(Valine)으로 바뀌는 결과를 가져온다. 이를 p.Glu7Val로 나타낸다. 분석에 사용한 기준 서열은 NCBI RefSeq의 NM_000518.5이며, FASTA 형식으로 저장하여 활용하였다.

3. 분석 도구 및 방법: 분석에는 Python과 생물정보학 라이브러리인 Biopython을 사용하였다. 먼저 Biopython의 SeqIO를 이용하여 FASTA 파일에 저장된 HBB 기준 서열을 불러왔다. 이후 CDS 영역에 해당하는 51~494번 위치의 염기서열을 추출하였다. 추출한 정상 서열에서 20번째 염기를 A에서 T로 치환하여 변이 서열을 만들었다. 다음으로 Biopython의 Seq.translate() 함수를 이용해 정상 서열과 변이 서열을 각각 아미노산 서열로 번역하였다. 번역된 두 서열을 비교하여 특정 위치의 아미노산이 어떻게 달라졌는지 확인하였으며, 전체 아미노산 길이도 계산하여 비교하였다. 마지막으로 Matplotlib을 이용해 정상 서열과 변이 서열의 아미노산 길이를 그래프로 나타내고, 분석 결과를 CSV 파일로 저장하였다.

4. 분석 결과: 정상 HBB 서열의 20번째 염기는 A였으며, 해당 염기를 T로 치환한 결과 코돈이 GAG에서 GTG로 바뀌었다. 이를 아미노산 서열로 번역했을 때 정상 서열에서는 글루탐산(E)이 나타났지만, 변이 서열에서는 발린(V)이 나타났다. 또한 정상 서열과 변이 서열의 아미노산 길이를 비교한 결과 두 서열 모두 147개로 동일했다. 즉, 아미노산의 전체 길이는 변하지 않았지만 특정 위치의 아미노산 종류가 달라졌음을 확인할 수 있었다. 이 결과는 DNA 염기 하나의 치환이 아미노산의 종류를 바꿀 수 있으며, 이러한 변화가 반드시 전체 아미노산 서열의 길이 변화로 이어지는 것은 아니라는 점을 보여준다.

5. 시각화 결과: 정상 HBB와 변이 HBB의 아미노산 길이를 Matplotlib으로 시각화하였다. 그래프에서 두 막대의 높이가 동일하게 나타났으며, 이를 통해 염기 치환 이후에도 전체 아미노산 길이가 유지되었음을 확인할 수 있었다.
