# DNA-Mutation-Analysis
DNA 염기 치환에 따른 아미노산 서열 변화 분석
본 프로젝트는 DNA 염기 하나의 치환이 아미노산 서열에 미치는 영향을 분석하는 것을 목적으로 한다. DNA는 A, T, G, C 네 종류의 염기로 구성되어 있으며, 염기 하나가 바뀌면 아미노산이 그대로 유지되거나 다른 아미노산으로 바뀔 수 있다. 또한 종결 코돈이 새롭게 형성되어 단백질 합성이 조기에 종료되는 경우도 발생할 수 있다. 이러한 변화를 확인하기 위해 Python의 생물정보학 라이브러리인 Biopython을 활용하고자 한다. 먼저 FASTA 파일에 기준 DNA 서열과 염기 치환이 일어난 서열을 입력한 후, Biopython의 SeqIO를 이용하여 서열 데이터를 불러온다. 이후 Seq 객체와 translate() 함수를 사용하여 각 DNA 서열을 아미노산 서열로 번역하고, 변이 전후의 아미노산 서열과 길이를 비교할 예정이다. 분석 결과는 DNA 길이, 아미노산 서열, 아미노산 길이 등의 항목으로 정리하여 CSV 파일로 저장하고, Matplotlib을 이용해 아미노산 길이의 차이를 그래프로 시각화할 것이다. 이를 통해 염기 치환 유형에 따라 아미노산 서열이 어떻게 달라지는지 비교할 수 있다.
